# healthy-repo

Skills for keeping a repository healthy, such as writing a concise README.

## Installation

```
/plugin install healthy-repo --marketplace binado/pluginado
```

## Skills

| Skill | Description |
| --- | --- |
| [create-readme](skills/create-readme/SKILL.md) | Create a concise README.md for a repository or package from a standard template. |
| [version-bump](skills/version-bump/SKILL.md) | Bump a package version, update CHANGELOG.md, open a release PR, and tag the release. |
