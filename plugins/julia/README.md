# julia

Skills for working with Julia, such as benchmarking code with BenchmarkTools.

## Installation

```
/plugin install julia --marketplace binado/pluginado
```

## Skills

| Skill | Description |
| --- | --- |
| [benchmark](skills/benchmark/SKILL.md) | Benchmark Julia code with BenchmarkTools by writing a script to `./.benchmark/<name>/benchmark.jl`, running it, and saving each trial's statistics to `results.md` and `results.csv` next to it. |

## MCP servers

The plugins uses the [`JuliaMCP.jl` server ](https://github.com/julia-vscode/JuliaMCP.jl), check their link for installation instructions.
