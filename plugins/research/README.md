# research

Fetch arXiv papers and sources, and write and compile LaTeX.

## Installation

```
/plugin install research --marketplace binado/pluginado
```

## Skills

| Skill | Description |
| --- | --- |
| [arxiv](skills/arxiv/SKILL.md) | Fetch an arXiv paper PDF and LaTeX source into .research/references using the bundled fetch script. |
| [latex](skills/latex/SKILL.md) | Write clear academic LaTeX and compile it with latexmk or tectonic via the bundled compile script. |
